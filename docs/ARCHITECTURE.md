# Boundaries and activation

`la.contracts` owns strict Pydantic v2 wire boundaries and sorted compact UTF-8 canonical hashes. `ingest` retains record offsets/separators/raw hashes and authorized spans; `inference` creates bounded evidence-bound candidates and discovery metadata. `review` is sole SQLite ruling authority. `convert` performs deterministic typed conversion and immutable bundle compilation; its separate evaluator-proposal seam is explicitly non-loadable and creates no product approval. `postgres` is a lazy separately authorized target/driver/version adapter. `providers` has distinct offline rules/mock and guarded live ranking, a separate B1 comparator and durable single-flight accounting. These are source implementations, not verified integrations.

`app.storage` supplies bounded reads, exclusive staged publication, per-run OS locks and cache CAS; `app.artifacts` supplies canonical contained artifacts. A run ID binds source/brief/samples/config; streamed refusals additionally bind observation identity. The final manifest commits the retained batch. Loading checks hashes and actual source resolution or explicit unmaterialized observation lineage. Exact input retries can finish interrupted intake without overwriting frozen members. SQLite current_state is generation authority; JSON pointers/archives recover from its actual stored generation and monotonic epoch. Bundles use final content identity, reports include renderer-code identity, and prior artifacts remain available. Export includes actual original inputs, generation and committed ruling lineage. Ranking changes display order only. See [storage](STORAGE.md) for crash assumptions and caps.

Optional SourceBatch.intake, Generation.discovery and Generation.filler are serialized only when supplied. Old absent-field hashes remain intact; new producers emit metadata before computing identities. Filler is an explicit declaration, not automatic approval of uncovered bytes. SQLite governs rulings and provider accounting; exports are projections rather than imported authorities. Unknown provider liability stops every later call until explicit content-bound billing reconciliation.

`report` renders a static escaped byte grid, preview, questions, history and readiness table with no scripts/server. The installed wheel includes only src/la. Root scripts import independent `evaluation` explicitly: injected RunnerPorts share visible inputs but never receive oracle/accepted-answer policy through inference callbacks. D5 evaluator proposals permit baseline/comparator decoding without weakening real journal/approval/load gates. Trusted callbacks are not OS isolation. Hidden assets remain external; no hidden corpus was generated.

Decimal wire values are strings; identifiers preserve zeros. Record identity includes source/framing hashes, ordinal and byte span, so identical duplicate rows survive. Generation/source/brief/policy changes invalidate dependent rulings and mapping approval. Incomplete mappings cannot be approved or loaded. Mapping completeness, transformation state, row parity, target validation, benchmark status and product acceptance are separate dimensions.

Deferred activation: establish Python/dependencies and a lock; run boundary, framing, replay/CAS/crash and full CLI checks; audit candidate recall and all declared policies; exercise public independent parity and mutations; provision only an authorized isolated PostgreSQL target, validate rollback/commit/readback/lost acknowledgement; establish real hidden-corpus OS custody before benchmark; pin provider/model/prices and spend authority before adding live calls. Current static construction provides no evidence that these have passed.

Root *.bak-* ignore excludes dated edit backups. SQLite, .la-runs and environment
files are private ignored artifacts. No lockfile, CI, Docker or deployment scaffold
was invented during construction. Public promotion remains separately controlled.
