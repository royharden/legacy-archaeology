# Constructed scope and unverified behavior

One synthetic account-ledger family: account_ref, description, exact balance,
effective_date and status. ASCII fixed-width LF/CRLF framing only. Raw bytes,
separators, offsets and duplicate ordinals are retained; partial authorization
reveals only permitted spans. Limits and unsupported declarations refuse explicitly.
Boundary/policy/name alternatives remain finite; missing true options require
unknown. Metadata counts distinguish physical spans, semantic names and policy
candidates. Candidate recall has not been measured.

Policies cover explicit padding/sign/scale0/2/3/precision/date century window,
blank/all-nines sentinel/null and disclosed status vocabulary. Zero, empty string,
leading zeros and SQL null remain distinct. No binary floating-point value
conversion or model-transformed rows. Unsupported legacy encodings, packed/zoned
decimal, mixed layouts, arbitrary copybooks, fuzzy matching, deduplication,
production databases, hosted services and multi-user access are outside this scope.

All source was constructed under Dirty Mode. AST parsing and focused source
inspection are the only performed checks; tests, demos, app imports, provider
calls, database connections, benchmark runs and services have not executed. No
dependency lock, tested provider API/SDK/model, dated verified price, actual cost,
observed latency or independent hidden-corpus custody is supplied. Declared ports,
authority packets and hashes are future gates, not evidence of authorization or
observed effects on their own. Root scripts remain outside the inference wheel.

Open validation work: real dependency/schema/runtime joins; candidate/policy
recall and edge cases; SQLite CAS/retry/replay/crash/concurrency; CLI containment,
approval invalidation and immutable artifacts; provider budgets/unknown costs;
actual target identity/schema/load/fresh readback/rollback/constraint/recovery;
independent scorer audit and finite mutations; external hidden custody/T2 freeze,
all five full-denominator arms; independent product acceptance. Source completion
does not turn any of those into passed. Public release still needs explicit authority.
